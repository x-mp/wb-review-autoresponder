# Security policy

Не создавайте публичный issue с токеном или данными покупателя. Отзовите скомпрометированный WB/OpenRouter-токен, смените `APP_ACCESS_TOKEN`, сохраните время и безопасное описание инцидента. В production используйте TLS, firewall, secret manager, резервные копии зашифрованного volume и минимальные scopes WB.
